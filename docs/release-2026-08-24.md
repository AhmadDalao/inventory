# Persistent Login, Packages, And Wristband Restock Release

Date: 2026-08-24

## Scope

This release adds secure browser login persistence, fixed package types, a storage-scoped wristband import workflow, downloadable import examples and preflight, and optional atomic wristband-code import during web manual restock.

## Behavior

- `Keep me logged in` defaults on and uses a rotating 30-day selector/validator token. Passwords are never stored.
- Logout revokes the current token. Password changes/resets, account disablement, and owner/admin revocation remove all saved logins for the user.
- Package presets use Individual, Pack, Box, Bag, Bottle, Container, Roll, Bundle, Carton, or Other. Only Other accepts a custom label.
- Wristband imports select a storage context before an item. Eligible zero-quantity item assignments remain searchable.
- Import preflight reports valid rows, duplicates, invalid codes, unknown SKUs, and conflicts before confirmation.
- Manual restock can attach one wristband CSV/XLSX per eligible item line. Valid code count must exactly match the converted whole-unit restock quantity.
- Combined restock and registry import is atomic. A failure rolls back stock and codes together.

## Compatibility

- Existing browser sessions and password login remain valid.
- Legacy package preset labels continue to render.
- The mobile API adds nullable `package_type` without removing existing package fields.
- Existing Flutter builds continue using label/conversion. Wristband spreadsheets remain web-only.
